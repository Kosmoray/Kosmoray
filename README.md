## Start here: Dayan Agent Skills

[Dayan Agent Skills](https://github.com/Kosmoray/dayan-agent-skills) is a public library of 56 beta Skills. Install only the one you need.

| Your task | Start with |
| --- | --- |
| Build a presentation from an outline | [Dayan Deck](https://github.com/Kosmoray/dayan-agent-skills/tree/main/skills/dayan-deck) |
| Understand a repository before changing it | [Dayan Orient](https://github.com/Kosmoray/dayan-agent-skills/tree/main/skills/dayan-orient) |
| Review a change before release | [Adversarial Reviewer](https://github.com/Kosmoray/dayan-agent-skills/tree/main/skills/dayan-adversarial-reviewer) |

Try the [quickstart](https://github.com/Kosmoray/dayan-agent-skills/blob/main/docs/quickstart.md), or inspect a [recorded repository-orientation run](https://github.com/Kosmoray/dayan-agent-skills/blob/main/examples/runs/orient-public-library-recorded.md). Package and offline checks are documented separately from [live-host compatibility](https://github.com/Kosmoray/dayan-agent-skills/blob/main/docs/compatibility.md).
